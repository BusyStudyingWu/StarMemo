# StarMemo 仅菜单栏模式

## 已确认需求

用户希望 StarMemo 运行时不占用 Dock，已接受不出现在 Command-Tab 切换列表，保留屏幕顶部星星入口。

## 方案

采用固定的菜单栏辅助应用模式：Info.plist 的 LSUIElement 设置为 true，启动时使用 accessory 激活策略，不再设置 regular。两个入口保持一致，避免启动时短暂出现 Dock 图标。

不新增显示 Dock 的设置开关，避免为本次明确需求增加配置和切换状态。仅从 Dock 取消固定无法隐藏运行中的普通应用，不采用此方法。

## 行为与边界

- 顶部星星菜单继续提供新建、打开、设置和退出入口；不依赖应用主菜单作为唯一入口。
- 点击便签仍能激活窗口并正常编辑；失焦不隐藏便签，置顶、拖动、改名保持现状。
- 设置窗口和文件对话框可获得焦点；退出继续执行现有保存确认和恢复数据流程。
- 从 Finder 再次打开应用时保留现有重开逻辑；不再把它描述为 Dock 专属行为。
- 不修改真实便签或用户的 Dock 固定项目。若用户自行固定过图标，需要自行取消固定。
- 不新增全局快捷键；不承诺辅助应用拥有普通应用的独立系统主菜单。

## 规格自查

范围限定为运行入口；不改变文档存储、Markdown 渲染、透明度及窗口几何。启动与运行策略一致，菜单入口与退出路径需保留。无待定项。

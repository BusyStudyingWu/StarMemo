# 恢复上次会话

## 目标

启动时恢复上次仍打开的便签、内容、标题和窗口位置，包括尚未保存成 Markdown 文件的草稿。明确关闭的便签不再恢复；没有可恢复便签时才新建空白便签。保留当前未提交的 0.1.7 菜单栏模式改动。

## 当前问题

NoteWindowCoordinator 仅为 dirty 文档写恢复副本，干净文档会移除副本。requestQuit 最后调用 close，连同恢复记录一起删除。因此现有异常恢复机制不是会话恢复。

## 选择的方案

使用独立、原子写入的会话快照记录仍打开的文档，不把“最近文件”当成会话。最近文件无法恢复未命名草稿，也无法表示哪些窗口已关闭。仅保留现有脏文档副本则遗漏已保存便签。

会话快照与现有恢复机制职责分开，但启动必须按文档 ID、规范化文件 URL 去重，避免重复打开。已有旧版本草稿继续兼容，明确关闭后两种记录都不能复活该便签。

## 操作规则

- 普通退出（菜单退出、应用收到正常终止请求）：保存会话快照后退出，不再逐张询问是否写入 Markdown 文件；未保存的内容留在本地快照，不擅自选择路径或覆盖磁盘文件。
- 主动关闭单张便签：有修改时继续询问“保存／不保存／取消”。保存成功或不保存后移出会话；取消、保存失败或取消路径选择时继续保留。
- 已保存且无修改的便签主动关闭后也移出会话，不删除磁盘文件。“不保存”丢弃本次修改，不等于删除原有 Markdown 文件。
- 隐藏全部不等于关闭，隐藏的便签下次启动也恢复显示。
- 会话写入失败：显示错误并拒绝正常退出，不能把未落盘内容当作已保护。关闭操作的记录更新失败也要报错，避免下次悄悄复活。
- 系统强制终止或断电只能恢复最近成功落盘的内容，不承诺绝对零丢失；运行中按编辑防抖及窗口变化更新记录。

## 文件与恢复冲突

- 已保存且无本地修改：重新读取磁盘最新内容。
- 有本地未保存修改：恢复快照文本并保持未保存状态，保留原文件基线用于现有外部修改冲突检查，不自动覆盖外部变更。
- 原文件丢失或无法读取：保留快照内容作为可另存的草稿并提示，不静默丢失内容。
- 损坏记录不能阻止其余便签恢复，必须提示恢复异常；不能静默覆盖唯一的损坏快照。
- 多显示器变化时避免窗口完全移出可用屏幕。2026-09-15 用户确认修订：恢复每张便签上次的主题、透明度和置顶，新建才使用默认值；主动修改全局设置仍应用到所有打开的便签，字号继续使用全局值。

## 验证与范围

使用临时目录与合成文档验证：保存和未保存便签混合退出重开、原位置恢复、连续重开无重复、主动关闭后不复活、不保存、取消关闭、写入失败阻止退出、外部文件变化、文件丢失、旧草稿迁移以及无会话时空白便签。回归现有退出和恢复检查，更新使用说明。

不读写真实便签，不自动安装启动正式应用，不提交或发布 Release。书面规格确认后编写实施计划。

## 自查

正常退出与主动关闭明确分离；不新增退出时“不保存”按钮，因此丢弃需在关闭单张便签时明确选择。快照不是用户指定的正式 Markdown 文件，也不是长期备份。无待定项。

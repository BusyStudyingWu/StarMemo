# 使用指南

## 新建与编辑

从“应用程序”启动 StarMemo，点击屏幕顶部的便签星星图标，新建便签或打开 Markdown 文件。应用不占 Dock，也不出现在 Command-Tab 列表中。

正文支持 Markdown 编辑与行内预览：当前编辑块可显示语法标记，离开后显示渲染效果。不承诺兼容全部 Obsidian 扩展、插件或双链。

## 标题栏与窗口

- 鼠标移到便签上沿，标题栏展开；平常移开后收起。
- 点击名字改名，点击正文或按回车确认，Esc 取消。改名期间仅移开鼠标不会提交。
- 拖动标题栏空白处移动窗口；正文用于编辑和选择文字。
- 图钉切换置顶，调色板调整当前便签颜色。
- 已保存便签改名会重命名磁盘上的文件；未保存便签使用该名字作为首次保存建议。

如果曾将 StarMemo 固定到 Dock，可右键图标，在“选项”中取消“在程序坞中保留”。

## 外观设置

菜单栏设置中的颜色、透明度、字号和置顶会应用于所有打开的便签；新建便签使用全局默认设置。
单张便签也可通过标题栏单独设置颜色和置顶。重开时保留各自的外观，下次修改对应全局选项时再统一覆盖。

透明度 **0% 为不透明，100% 为背景全透明**；文字、待办框和控件不随背景淡化。背景复杂时建议降低透明度。

系统启用“辅助功能 → 显示 → 减少透明度”时，背景暂时不透明、滑块不可用；原设置保留，关闭该系统选项后恢复。

## 保存、关闭与退出

| 操作 | 结果 |
| --- | --- |
| 保存（⌘S） | 写入 Markdown 文件；首次保存选择路径 |
| 关闭单张便签 | 有未保存修改时询问保存／不保存／取消；关闭后不再恢复 |
| 正常退出应用 | 保存仍打开的便签会话，下次恢复正文、标题、位置及外观 |
| 隐藏便签 | 不等于关闭，便签仍属于当前会话 |

“不保存”丢弃本次修改，不删除已有 Markdown 文件。正常退出保存会话也不等于把修改写回正式文件。

重开未修改的已保存文件时读取磁盘内容；存在未保存修改时保留会话内容，之后保存会检查外部修改。原文件丢失时恢复为可另存的草稿。
会话写入失败会提示并阻止正常退出；损坏记录会尝试保留原始备份。

## 常用快捷键

仅在 StarMemo 处于活动状态时生效，不是全局快捷键。

| 操作 | 快捷键 |
| --- | --- |
| 新建 / 打开 / 保存 | ⌘N / ⌘O / ⌘S |
| 重命名 | ⌘⇧R |
| 置顶 / 取消置顶 | ⌘⇧P |
| 关闭便签 / 退出应用 | ⌘W / ⌘Q |

## 注意事项

- 重要内容请保存为文件并独立备份；强制结束或断电可能丢失最近输入。
- 正式文件位于你选择的位置；会话与恢复记录位于用户 Application Support 下的 StarMemo 目录，没有应用层加密。
- 遇到外部文件冲突，不确定时先取消或另存，避免覆盖他人的修改。
- 安装包未做 Apple Developer ID 签名和公证。不要关闭系统安全防护来运行来源不明的应用。
- 目前提供 Apple Silicon 安装包，无自动更新；Intel 和多显示器连续拖动体验尚未完成验收。
- 随附 MarkdownEngine 核心，未引入额外代码高亮和 LaTeX 适配器。
- 升级前保存重要内容并退出旧版，再替换应用。报告问题时附系统、应用版本和复现步骤，截图先去除私人内容。

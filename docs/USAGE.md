# 使用指南与注意事项

## 开始使用

1. 从“应用程序”启动 StarMemo。
2. 在屏幕顶部菜单栏找到便签星星图标，选择“新建便笺”或“打开 Markdown…”。
3. 在正文输入 Markdown。点击正文编辑时，当前编辑块可显示语法标记；离开编辑状态后显示渲染效果。
4. 选择“保存当前便笺”。首次保存会要求选择 `.md` 文件的位置。

0.1.7 起，StarMemo 只保留顶部星星入口，不显示运行中的 Dock 图标，也不出现在 Command-Tab 切换列表。
新建、打开、设置和退出请使用星星菜单；不再以左上角是否显示 StarMemo 主菜单判断能否编辑。
从“应用程序”再次打开会显示已有便签；没有便签时才新建。如果以前手动将 StarMemo 固定到 Dock，请右键图标，在“选项”里取消“在程序坞中保留”。

## 设置的作用范围（0.1.5 起）

- 设置只有一组：颜色、透明度、字号、置顶。修改立即应用于所有打开的便签，新建便签使用默认值。
- 透明度数值越大背景越透明：0% 完全不透明，100% 背景全透明。没有隐藏下限或二次换算，文字、待办框和操作控件不随背景淡化。
- 顶部图钉和调色板仍可单独调整一张便签。0.1.9 起重开会保留该便签上次的主题、透明度和置顶；下一次主动修改对应全局选项时再统一覆盖。字号仍为全局设置。
- 首次升级以原全局默认设置初始化；旧背景浓度仅迁移一次。旧单张外观不再覆盖全局设置，正文和窗口位置不变。

为使实际透明度与滑块一致，移除了原先独立叠加的磨砂底板。高透明度会露出桌面细节，复杂背景可能降低可读性，可降低透明度或切换颜色。

系统开启“辅助功能 → 显示 → 减少透明度”时，滑块置灰并说明原因，背景暂时不透明；原值保持，关闭该系统选项后恢复。

## 标题栏与窗口

- 鼠标进入便签上沿时展开标题栏，平常移开后收起。
- 单击名字进入改名。点击正文或按回车确认；Esc 取消。
- 改名期间仅移开鼠标不会提交或收起。
- 拖动标题栏空白处移动窗口；正文用于编辑和选择文字。
- 图钉切换置顶，调色板更改颜色，关闭按钮关闭当前便签。
- 已保存便签改名会实际重命名磁盘上的文件；未保存便签的名字用于首次保存建议。

## 常用快捷键

快捷键在 StarMemo 处于活动状态时使用，不是全局快捷键。

| 操作 | 快捷键 |
| --- | --- |
| 新建 | ⌘N |
| 打开 Markdown | ⌘O |
| 保存当前便签 | ⌘S |
| 重命名 | ⌘⇧R |
| 关闭当前便签 | ⌘W |
| 置顶 / 取消置顶 | ⌘⇧P |
| 退出应用 | ⌘Q |

## 保存、恢复与隐私

- 0.1.8 起，正常退出会保留所有仍打开的便签，包括未保存成文件的草稿，下次启动自动恢复内容、标题和位置；没有会话才新建空白便签。
- 正常退出不再逐张询问是否写入 Markdown 文件。想正式保存到指定路径仍使用“保存当前便笺”。隐藏便签不等于关闭。
- 主动关闭单张便签时仍询问保存／不保存／取消。关闭后不再自动恢复；“不保存”只丢弃本次修改，不删除已有 Markdown 文件。
- 会话写入失败会提示并阻止正常退出；读取原记录失败时不覆盖原文件。损坏记录会尽量恢复可读部分并保留损坏备份，原 Markdown 文件丢失时恢复为可另存的草稿。
- 已保存且无修改的文件重开时读取磁盘最新版本；有本地未保存修改则保留本地内容，之后保存仍检查外部修改冲突。
- 强制结束、断电只能恢复最近成功写入的记录，不能保证最后一刻的输入。会话及损坏备份包含正文，保存在应用本地目录，不是加密备份。
- 恢复副本是异常退出时的辅助保护，不是已保存的正式 `.md` 文件，也不等于备份。
- 关闭单张便签时，有未保存修改会询问“保存 / 不保存 / 取消”。“不保存”会丢弃本次修改；请谨慎选择。
- 文件被其他程序修改时，先读清冲突提示。覆盖会替换磁盘内容；不确定时优先取消或另存为。
- 正式文件在你选择的位置；恢复记录位于用户的 Application Support 下的 StarMemo 目录，偏好与最近文件记录使用 UserDefaults。
- 文件和恢复记录没有应用层加密。请不要把恢复目录、真实便签或带私人内容的截图上传到 Issue。
- 更新、卸载或清理应用数据前，请把重要便签保存为文件并另外备份。

## 当前限制

- 这是早期版本，尚无自动更新功能。
- 安装包面向 Apple Silicon；Intel 与多显示器连续拖动体验尚未验收。
- 不承诺完整兼容 Obsidian 插件、双链或全部扩展语法。
- 随附的是 MarkdownEngine 核心，未引入额外代码高亮和 LaTeX 适配器。
- 安装包未做 Developer ID 签名和 Apple 公证。无法核实来源时不要绕过安全提示。
- 遇到问题请记录系统版本、芯片类型、StarMemo 版本和最小复现步骤。先保存内容，再尝试退出重开。

# StarMemo 0.1.3（Build 4）

修复空便签及短便签点击正文下方空白处后，无法直接输入的问题。

- 空便签点击正文空白处可从第一行输入；有内容时从文末继续，不插入额外空行。
- 修复改名框收起时清除正文输入焦点的时序问题，不从其他输入控件抢焦点。
- 新增真实鼠标点击与键盘输入回归检查，覆盖空文本、短文本、改名后和失焦后场景。

## 安装

下载 `StarMemo-0.1.3-macOS-arm64.dmg`，打开后将应用拖入“应用程序”。升级前保存便签并退出旧版。
适用于 Apple Silicon（M 系列芯片）和 macOS 14+，不提供 Intel / Universal 安装包。
启动后通过屏幕顶部菜单栏的便签星星图标进入。

仓库保持私有，下载需具备仓库访问权限。当前安装包没有 Developer ID 签名或 Apple 公证；不要关闭系统安全功能。无法确认来源时请停止安装或自行构建。

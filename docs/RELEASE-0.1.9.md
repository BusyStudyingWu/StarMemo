# StarMemo 0.1.9（Build 10）

包含 0.1.7–0.1.9 的更新：

- 仅保留顶部星星入口，不再占用 Dock 或 Command-Tab。
- 正常退出自动保留仍打开的便签及未保存草稿，下次恢复内容、标题和窗口位置。
- 修复重开时主题、透明度及置顶状态被全局默认值覆盖的问题；新建使用默认值，主动修改全局设置仍同步所有打开的便签。
- 主动关闭便签仍提供保存／不保存／取消，已关闭便签不再恢复；会话写入失败阻止正常退出。
- 保留外部文件冲突保护；缺失文件可恢复为草稿，损坏会话记录提示并备份。

## 升级与注意事项

适用于 Apple Silicon（M 系列）及 macOS 14+。先将重要笔记保存为 Markdown 文件，再退出旧版，将 DMG 中的 StarMemo.app 拖入“应用程序”替换。

从 0.1.6 或更早版本升级，尤其需要先保存笔记：旧版正常退出会清除恢复记录。新版无法找回已丢弃的内容；此前被旧版重置的主题和置顶需要重新设置一次。

正常退出不再逐张弹文件保存提示，本地会话快照不等于正式保存为 Markdown 文件，也不是加密或长期备份。强制结束或断电只能恢复最近成功写入的内容。

仓库保持私有，下载需要访问权限。安装包未做 Developer ID 签名和 Apple 公证；无法确认来源时请停止安装或从源码构建，不要关闭系统安全功能。

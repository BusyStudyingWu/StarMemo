# 状态栏图标

图形为 18 pt 的折角便签与空心星星，线宽 1.25 pt。路径保存在 `Sources/StarMemoUI/App/StatusBarIcon.swift`。

菜单栏标签必须输出标准 `Image`。不要直接把 `Shape` 作为 `MenuBarExtra` 标签：离屏预览可以正常绘制，并不代表系统菜单栏能显示它。

当前实现使用 `NSImage` 绘图回调保存矢量路径，设置 `isTemplate = true`，再通过 `Image(nsImage:)` 接入。由系统根据菜单栏外观处理颜色，不显示应用名称。

验证分两层：

- 自动化：标签类型、模板标记、尺寸、无障碍名称，以及 1× / 2×、深浅色下的透明中心和可见线条。
- 实机：启动独立测试程序或安装包，确认系统菜单栏中的图标可见、菜单能打开，退出后入口消失。离屏测试不能代替此项。
